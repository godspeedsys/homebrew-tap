# homebrew-tap

Homebrew formulae for command-line tools from godspeedsys. Install any of them with
`brew install godspeedsys/tap/<tool>`; `brew upgrade` keeps them current.

| Tool | Install | What it is |
|---|---|---|
| `submerse` | `brew install godspeedsys/tap/submerse` | The [Submerse](https://submerse.it) command line: save, organize and label bookmarks from a terminal. macOS (Apple silicon and Intel). [Help](https://submerse.it/help#command-line) |

Each formula installs a prebuilt binary from its tool's releases repository (for `submerse`,
[godspeedsys/submerse-cli](https://github.com/godspeedsys/submerse-cli/releases)) and checks it against the
SHA-256 in the formula. Questions: support@submerse.it.
